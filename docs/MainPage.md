# QuasarEngine

QuasarEngine is a cross-platform 3D engine written in C++20, with its own editor.

This site is the reference of the engine public API. It is generated by Doxygen from the comments in the
headers of `engine/include`, every time a change is merged.

Use the menu on the left to browse namespaces, classes and files, or the search box to find a name.

To build the engine or contribute, see the
[repository on GitHub](https://github.com/ultirisstudio/QuasarEngine).
